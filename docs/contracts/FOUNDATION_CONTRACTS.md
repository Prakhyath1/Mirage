# MIRAGE Foundation Contracts (T1)

Stable public contracts exposed by the T1 foundation & runtime to **T2**
(agentic engine), **T3** (security / VFS / containment) and **T4**
(dashboard, testing, integration). Everything documented here lives in
`app/models.py`, `app/core/`, `app/events/bus.py`, `app/runtime/` and
`app/storage/`. Consumers must depend only on this surface, never on
private implementation details.

---

## 1. Typed contracts (`app/models.py`)

All contracts are **frozen** dataclasses (`@dataclass(frozen=True, slots=True)`).
Mutate nothing; use the provided copy helpers.

### Session

| field | type | notes |
|---|---|---|
| `session_id` | `str` | server-generated, see §3 |
| `created_at` / `updated_at` | `float` | epoch seconds (UTC) |
| `status` | `SessionStatus` | `CREATED` → `ACTIVE` → `CLOSED` |
| `source_address` | `str` | attacker IP for research |
| `source_port` | `int` | |
| `username` | `str` | attempted username |
| `auth_method` | `str` | e.g. `"password"`, `"publickey"` |
| `auth_success` | `bool` | verdict only — **passwords are never stored** |
| `cwd` | `str` | defaults `"/home/admin"` (decoy identity, T3 discipline) |
| `metadata` | `dict` | free-form, size-capped at storage |

Factory: `Session.new(source_address="", source_port=0, username="", auth_method="", auth_success=False, cwd="/home/ubuntu", metadata=None, session_id=None)` — status starts `CREATED`, ID generated server-side unless supplied.

Change: `session.with_changes(**fields)` → frozen copy with `updated_at` refreshed. **Only the SessionManager constructs modified sessions**; the lifecycle (§4) enforces legal transitions.

`session_id, created_at, updated_at, status, source_address, username, command_count (default 0), last_command (Optional[str]), metrics (dict)`.

### HealthStatus

`status ("ok"|"degraded"|"error"), version="0.2.0", environment="development", security_mode="strict", database_connected=False, event_bus_running=False, uptime_seconds=0.0, active_sessions=0, details={}`. Property `is_ready` → `status == "ok"`. Contains **no secrets and no internal paths**.

## 2. Enums

```python
SessionStatus : CREATED | ACTIVE | CLOSED            # UPPERCASE values
ResultType    : fallback | vfs | security | agentic | containment | error
Severity      : debug | info | warning | high | critical
EventType     : session.created, session.status_changed, session.closed,
                command.submitted, command.dispatched, command.completed,
                security.decision, security.honeytoken_access,
                security.containment_triggered, runtime.error
```

`EventType` is open: T2/T3 may publish their own dotted string types; the
bus does not restrict `event_type`. `ResultType` tells the pipeline which
subsystem answered (T1 fallback → `fallback`, T2 agentic → `agentic`,
T3 VFS/security/containment → `vfs`/`security`/`containment`).

## 3. Identifiers (`app/core/ids.py`)

- Generated by the **server only** from `secrets.token_urlsafe(24)`
  (URL-safe → lowercase alnum, entropy ≥ 128 bits).
- Formats: `sess_<32 chars>` (session), `cmd_<32 chars>` (command),
  `evt_<32 chars>` (event). Full regex: `^[a-z]+_[a-z0-9]{26,32}$`.
- `is_valid_id(value)` validates shape at every boundary (API, runtime).
- **Never trust a client-supplied ID** — it is accepted only as a lookup
  key after validation, never as a path, query, or code.

## 4. Session lifecycle (SessionManager, `app/runtime/session_manager.py`)

State machine:

```
CREATED ──activate──▶ ACTIVE ──close──▶ CLOSED
CREATED ──close────▶ CLOSED
```

Any other transition raises `SessionStateError`. `close()` on an already
`CLOSED` session is idempotent (no error). Events emitted:
`session.created`, `session.status_changed`, `session.closed`.

Key APIs: `create(source_address=…, source_port=…)`, `get(session_id)`,
`activate(session_id)`, `close(session_id)`, `record_auth(...)`,
`update_metadata(session_id, dict)`, `summary(session_id)`.

## 5. Command pipeline (`app/runtime/dispatcher.py`)

```
CommandRequest ─▶ CommandDispatcher ─▶ CommandHandler.handle()
                                              │
CommandResult ◀──────────────────────────────┘
      │
      └─▶ SecurityEvent(command.dispatched / command.completed)
```

### CommandHandler protocol (T2/T3 implement this)

```python
@runtime_checkable
class CommandHandler(Protocol):
    name: str
    async def handle(self, request: CommandRequest) -> CommandResult: ...
```

- `dispatcher.register(handler)` — **LIFO**: the last registered handler
  that returns a truthy `claims(request)` (optional method) wins. T3's
  security/VFS handlers should register *after* the fallback.
- Handler exceptions are isolated: the dispatcher catches, emits
  `runtime.error` (severity `high`), and falls through to the next
  handler / the fallback. One bad handler can never kill the pipeline.
- Intake is persisted **before** any handler runs (evidence is never lost
  even on crash).
- `SafeFallbackHandler` (name `"safe_fallback"`) is the terminal handler:
  static simulated replies (`whoami` → the decoy user, …), exit 127
  `bash: {first-token}: command not found` for unknown commands. **It
  never executes anything on the host.**

### Error codes (validated intake, surfaced in API `message`)

| code | meaning |
|---|---|
| `command.empty` / `command.nul_byte` / `command.too_long` | command text rejected at intake |
| `session.missing` / `session.invalid_id` / `session.not_active` | session rejected |

## 6. Event bus (`app/events/bus.py`)

Async, in-process, publish/subscribe. **Wildcard delivery**: every
subscriber receives every event; filter on `event_type` yourself.
Replaceable later by Redis/ZeroMQ behind the same interface.

```python
async def subscribe(self, handler: EventHandler) -> None      # handler(event)
def unsubscribe(self, handler: EventHandler) -> None
async def publish(self, event: SecurityEvent) -> None         # after close(): no-op
async def publish_many(self, events: list[SecurityEvent]) -> None
def close(self) -> None                                        # idempotent
@property running -> bool
def subscriber_count(self) -> int
@property stats -> dict
```

- `EventHandler` protocol: `async def __call__(self, event: SecurityEvent) -> None`.
- Per-handler try/except isolation: one failing subscriber cannot break
  others. Delivery is serial (ordering guaranteed).
- Events are immutable — handlers must copy before mutating.
- The runtime subscribes one persistence mirror (`_persist_event`) so
  every published event is also written to the database.

## 7. Storage repositories (`app/storage/database.py`)

SQLite today (WAL, `foreign_keys=ON`); **method signatures are the
PostgreSQL migration contract** — schema SQL is isolated in
`app/storage/schema.py` (`SCHEMA_VERSION` stamped in `schema_info`).
Tables: `sessions`, `commands`, `command_results`, `events` (events have
no FK so forensic records survive session pruning); every lookup column
indexed.

```python
sessions.create(Session) / get(session_id) / update(Session)
sessions.count_by_status(status) / list_recent(limit) / summary(session_id)
commands.create(CommandRequest) / get(command_id) / list_for_session(session_id)
commands.count_for_session(session_id) / save_result(CommandResult, session_id) / get_result(command_id)
events.save(SecurityEvent) / get(event_id) / list_for_session(session_id) / list_recent(limit)
storage.health_check() -> bool
storage.initialize() / storage.close()
```

Bounded blobs: JSON columns capped at 256 KiB — oversized content is
replaced by `{"truncated": True, "size": <bytes>}`; `stdout`/`stderr` are
stored verbatim (simulated output is trusted).

## 8. Runtime composition (`app/runtime/service.py`)

`MirageRuntime` is the composition root: `settings`, `storage`, `bus`,
`sessions` (SessionManager), `dispatcher`. `initialize()` /
`shutdown()` are idempotent. `submit_command(session_id, raw_command)`
is the **single validated funnel** every input source must use.

`RuntimeResult` (`app/core/result.py`) — `ok`, `value`, `error_code`,
`error_message` with `success(value)` / `failure(code, message)` —
carries outcomes across module boundaries; failures are values, not
exceptions leaking to callers.

| route | method | purpose |
|---|---|---|
| `/health` | GET | liveness |
| `/ready` | GET | readiness (DB connected, bus running, active sessions) |
| `/dev/sessions` | POST | create session (development only) |
| `/dev/sessions/{session_id}` | GET / DELETE | summary / close |
| `/dev/sessions/{session_id}/commands` | POST | submit command through the funnel |

Error envelope (never a stack trace):

```json
{"error": "<machine_code>", "message": "<safe human text>"}
```

Malformed IDs → 400, validation failures → 422, unknown `sess_*` → 404.

## 10. SSH preparation (`app/runtime/ssh.py`)

`SSHTransportObserver` protocol + `SSHAdapterBase` skeleton: transport
callbacks (`connection_accepted`, `authentication_attempt`,
`pty_requested`, `command_received`, `session_closed`) translated into
runtime calls. The future AsyncSSH task plugs in **without touching the
runtime**. Adapters must validate lengths at the boundary and never
forward credentials.

## Security invariants (binding on all consumers)

1. **Attacker input never becomes host OS execution.** No `os.system`,
   no `subprocess` with attacker strings, no `shell=True`, no
   `eval`/`exec` on attacker data.
2. Untrusted fields (IDs, commands, paths, headers, metadata) are
   validated at boundaries before use.
3. Secrets are env-configured, never hardcoded, never logged.
4. Security controls are never disabled to make tests pass.
